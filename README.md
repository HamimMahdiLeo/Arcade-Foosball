# ⚽ Arcade Foosball

A simple 3D arcade-style foosball game made with Unity.

### Features
-  Keyboard & gamepad support
-  3D foosball gameplay

### What's new
-  CPU Control added
-  Player now can choose team with 3 control methods
-  Fixed small bugs
-  Available for browsers
